Life in Glyph

Four hand-crafted demonstrations of what one English prompt to an AI agent can produce when the AI knows how to write Glyph. Each page picks a subject anyone can recognize — a NASA mission, a heartbeat, a leopard, a sunflower — and shows the full chain: prompt → JSON spec → byte-locked SVG → page. Designed to be enjoyed by a 5-year-old and a 70-year-old in the same sitting.

Why we made this

Most viz grammars are designed for charts — bars, lines, scatter plots. They handle survey data and revenue dashboards beautifully and stop there.

Glyph is designed to handle math, physics, and biology too. The same JSON grammar that draws a bar chart can also integrate an ODE, solve a PDE, walk a recurrence, or trace a photon through curved spacetime. The output is always the same kind of object: a byte-stable SVG that an AI agent can author from English.

"Life in Glyph" is four hand-crafted proofs of concept. Each page picks a familiar subject and walks the reader through: the English prompt a user might give Claude → the JSON spec Claude writes in response → the SVG the Glyph compiler produces → the animated page the user sees.

None of these required code from the user. All of them are deterministic — same prompt, same render, every platform, every time. That's the contract this grammar makes.
