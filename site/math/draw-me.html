The mission, in three acts

Each act of the journey corresponds to one phase of the path above. Real Artemis I numbers from NASA's mission log.

PHASE 1
Days 1 – 6

Outbound transit

The Space Launch System rocket boosts Orion onto a trans-lunar trajectory. The spacecraft coasts upward and outward, gravity gently bending its path toward the Moon — a four-day journey across about 240,000 miles of space.

PHASE 2
Days 6 – 22

Distant Retrograde Orbit

Orion swings around the Moon in a wide, stable orbit — backwards relative to the Moon's own motion. It travels 64,000 km beyond the lunar far side, farther than any human-rated spacecraft has ever flown.

PHASE 3
Days 22 – 25

Return & splashdown

A return burn slingshots Orion back toward Earth. The capsule re-enters at 25,000 mph (Mach 32), the heat shield handling temperatures half as hot as the Sun's surface. Splashdown: Pacific Ocean, December 11, 2022.

How Glyph drew it

Claude translates the English prompt into this JSON spec. Glyph compiles the spec to a deterministic SVG — byte-identical every run, every platform.

The Glyph spec JSON

// orion-journey.json — what Claude writes for the prompt above
{
  "version": "glyph/0.1",
  "title": "Orion's Journey: Earth → Moon → Earth",
  "data": {
    "function": {
      "shape": "function",
      "parameter": { "name": "t",
                     "min": 0, "max": 1,
                     "samples": 400 },
      // three phases, switched by t — outbound, DRO, return
      "xExpr": "(t < 0.3) ? (0.6 + 4.9*(t/0.3))
              : ((t < 0.7)
                  ? (8 + 2.5*cos(PI - 1.5*PI*((t-0.3)/0.4)))
                  : (8 - 7.4*((t-0.7)/0.3)))",
      "yExpr": "(t < 0.3) ? (sin((t/0.3)*PI)*1.5)
              : ((t < 0.7)
                  ? (2.5*sin(PI - 1.5*PI*((t-0.3)/0.4)))
                  : (-2.5*(1-(t-0.7)/0.3)
                       - sin(((t-0.7)/0.3)*PI)*0.5))"
    }
  },
  "layers": [{ "mark": "line",
               "encoding": { "x": { "field": "x" },
                            "y": { "field": "y" } } }],
  "animation": { "kind": "draw-in",
                  "duration_ms": 12000,
                  "easing": "ease-in-out" }
}

The three-phase ternary is the whole "mission profile" — phase boundaries at t = 0.3 and t = 0.7 partition the timeline into outbound, DRO, and return. View on GitHub.
